# ФлораСклад

Учёт цветочного магазина: остатки по партиям и свежесть, операции (приход, продажа,
списание), букеты с рецептами и сборкой, аналитика по выручке и прибыли, AI-ассистент,
который понимает команды обычным текстом, и боты в Telegram и MAX.

## Быстрый старт

```bash
git clone <адрес репозитория> florasclad
cd florasclad
pnpm install
cp .env.example .env      # заполните DATABASE_URL и AUTH_ROOT_*
# создайте базу, затем:
set -a && source .env && set +a
pnpm --filter @workspace/db run push
pnpm --filter @workspace/api-server run dev        # терминал 1
PORT=5173 pnpm --filter @workspace/flower-stock run dev   # терминал 2
```

Подробнее — [docs/quickstart.md](docs/quickstart.md).

## Что внутри

| Пакет | Что это |
| --- | --- |
| `artifacts/api-server` | API: склад, букеты, аналитика, ассистент, боты |
| `artifacts/flower-stock` | интерфейс магазина |
| `lib/db` | схема PostgreSQL (Drizzle) |
| `lib/api-spec` | контракт API (`openapi.yaml`) |
| `scripts` | сиды, проверки, замеры вёрстки |

Стек: Node.js 24, TypeScript, Express 5, PostgreSQL 16, Drizzle ORM, React 19, Vite,
TanStack Query, Tailwind. AI — любой OpenAI-совместимый провайдер.

## Требования

- Node.js 24 и pnpm
- PostgreSQL 16
- для проверок интерфейса — Chrome или Edge

Провайдер AI **не обязателен**: без него склад, букеты, операции и аналитика работают
полностью, а ассистент отвечает, что провайдер не настроен.

## Проверки

```bash
node scripts/src/status.mjs --checks
```

Проверки измеряют результат, а не «смотрят глазами»: они считают остатки, читают тела
запросов и геометрию DOM. Подробнее — [docs/checks.md](docs/checks.md).

## Лицензия

MIT — **разрешено всё**: пользоваться, менять под свои задачи, распространять и продавать,
в том числе как готовый сервис. Единственное условие — сохранить текст лицензии и указание
авторства. Подробности в [LICENSE](LICENSE).

Проект задуман как основа, а не как готовый продукт под конкретный магазин: разделы, отчёты и
подсказки ассистента рассчитаны на цветочный магазин, но код открыт для переделки под себя.

## Если не хочется разворачивать самому

Проект можно взять как есть и поднять на своём компьютере или сервере — инструкция выше.
Если разворачивать не хочется, автор проекта развивает hosted-версию: тот же склад, но на его
сервере, с отдельным входом и отдельной базой для каждого магазина. Это не часть этого
репозитория: код здесь самодостаточен и без него.

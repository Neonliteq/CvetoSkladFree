# Развёртывание

Проект работает как обычный процесс Node.js. Ниже — путь для Ubuntu, но ничего
специфичного для конкретного хостинга здесь нет.

## Что понадобится

- сервер с Ubuntu 24.04 и домен, если нужен доступ из интернета;
- Node.js 24, pnpm, PostgreSQL 16;
- nginx и certbot — для HTTPS.

## Шаги

1. Создайте пользователя и каталог приложения, скопируйте туда репозиторий.
2. Создайте базу и заполните `.env` (образец — `.env.example`).
3. `pnpm install && pnpm run build`
4. `set -a && source .env && set +a && pnpm --filter @workspace/db run push`
5. Поставьте службу из `deploy/florasklad-api.service`, заменив пользователя и пути.
6. Настройте nginx по `deploy/nginx-example.conf` и выпустите сертификат:
   `certbot --nginx -d ваш-домен`
7. Проверьте: `curl -s https://ваш-домен/api/healthz`

## Обновление

```bash
bash deploy/update.sh
```

Скрипт делает резервную копию базы, забирает изменения, пересобирает, применяет схему и
перезапускает службу. **Резервные копии проверяйте**: копия, которую ни разу не
восстанавливали, копией не является.

## Боты

Telegram и MAX включаются переменной `BOTS_ENABLED=1` и токенами в `.env`. До появления
публичного адреса с HTTPS они бесполезны: Telegram доставляет сообщения только по HTTPS,
а MAX в режиме длинного опроса не рекомендуется для постоянной работы.
